Станок обезволашивания
Таксидермия
<&recipe>Станок обезволашивания убирает всё лишнее со шкур с помощью вращающегося цилиндра с лезвиями, которые соскабливают шерсть и плоть.

<&blades>Для использования станка обезволашивания, нужно установить лезвия для обезволашивания на цилиндр, нажав ПКМ по машине с лезвием в руке.

Результат обработки получит статус <link;advancedtfctech:beamhouse;"Фабричного производства";machine_made>, если на предмет на входе имел такой же статус.

По умолчанию потребляет 20 IF/тик.
